# A browser implementation of a probability wheel

A probabiity wheel is a circular widget made up of two wedges, one orange and one blue. The angle of the two wedges can be varied by the user. As one wedge increases in size the other decreases so that together they make up the full circle. 

The app is accessible as a webpage that runs entirely client side, interactively. The user drags the edge of the circular region to change the angle of one wedge relative to the other.  The web page has a readout that indicates the percentage of the orange wedge as set by the user.
